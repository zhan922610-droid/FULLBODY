# Full Body Tracker 🏋️

Мобильное PWA-приложение для ведения силовых тренировок по программе Full Body на 3 дня в неделю.

## Возможности

- 📱 Работает как нативное приложение на Android и iPhone
- 🌐 Офлайн-режим после первого открытия
- 💾 Все данные хранятся локально (IndexedDB)
- 🔄 Автоматическое копирование весов из прошлых тренировок
- ⏱ Встроенный таймер отдыха
- 📊 Аналитика прогресса с графиками
- 🔥 Поддержка миорепсов и дроп-сетов
- 💾 Экспорт/импорт резервных копий
- 🌙 Тёмная и светлая тема

## Программа тренировок

### День 1
Тяга верхнего блока, Махи с гантелями, Жим гантелей на наклонной, Тяга горизонтального блока одной рукой, Сгибание рук на наклонной, Разгибание рук на блоке, Болгарские выпады, Скручивания на босу, Икроножные в Смите, Сгибание кисти

### День 2
Отжимания на брусьях, Тяга горизонтального блока, Сгибание ног сидя, Жим гантелей сидя, Пуловер, Молотки на блоке, Разгибание рук над головой, **Икры — Миорепс**

### День 3
Тяга вертикального блока одной рукой, Разгибание кисти, Разгибание ног, Сведение рук в бабочке, Обратная бабочка, Румынская тяга, Махи на блоке, **Скручивания — Дроп-сет**

## Запуск проекта

### Требования
- Node.js 18+
- npm

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Локальный запуск (режим разработки)
npm run dev

# Сборка для продакшена
npm run build
```

### Локальный запуск собранной версии

```bash
npm run build
npx serve dist
```

## Установка на смартфон

### Android (Chrome)
1. Откройте приложение в браузере Chrome
2. Нажмите на три точки в правом верхнем углу
3. Выберите «Добавить на главный экран» или «Установить приложение»
4. Подтвердите установку

### iPhone (Safari)
1. Откройте приложение в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх)
3. Прокрутите вниз и выберите «На экран Домой»
4. Нажмите «Добавить»

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub
2. Запушьте код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. Соберите проект:
   ```bash
   npm run build
   ```
4. Для GitHub Pages добавьте в `vite.config.js`:
   ```js
   base: '/REPO_NAME/'
   ```
5. Задеплойте папку `dist` через GitHub Pages или используйте `gh-pages`:
   ```bash
   npm install -D gh-pages
   npx gh-pages -d dist
   ```

## Резервное копирование

Данные хранятся локально на устройстве. Рекомендуется регулярно делать резервные копии:

1. Откройте Настройки в приложении
2. Нажмите «Экспорт данных»
3. Сохраните JSON-файл в надёжное место

Для восстановления данных:
1. Откройте Настройки → «Импорт данных»
2. Выберите ранее сохранённый JSON-файл

## Технологии

- React 18
- Vite
- Tailwind CSS 4
- IndexedDB (через idb)
- Service Worker для офлайн-режима
- Web App Manifest для PWA

## Структура проекта

```

├── App.tsx              # Главный компонент с навигацией
├── main.tsx             # Точка входа
├── index.css            # Стили
├── types.ts             # TypeScript типы
├── db.ts                # IndexedDB обёртка

└── components/
    ├── Home.tsx         # Главный экран
    ├── WorkoutExercise.tsx  # Экран упражнения
    ├── RestTimer.tsx    # Таймер отдыха
    ├── History.tsx      # История тренировок

public/
├── manifest.json        # PWA манифест

└── icons/               # Иконки приложения
```

## Важные замечания

- ⚠️ Очистка данных браузера приведёт к потере всех данных
- ⚠️ При смене устройства необходимо перенести резервную копию
- ✅ Приложение не требует сервера или интернета после первого открытия
- ✅ Данные не передаются третьим лицам
